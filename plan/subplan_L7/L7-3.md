3. **TODO** — Levenberg–Marquardt, because a sail's trajectory over days is nothing like
   linear in its initial state and plain Gauss–Newton diverges from it.

   *Ruled 2026-10-06, on the rule-4 report.* The damping is DTU's Algorithm 3.16 in the scaled
   variables, the scaling recomputed at each iterate and the gain ratio taken on the whole
   objective, prior included: scale-invariant, as everything decided from the matrix must be. In
   the executor's exploratory run plain Gauss–Newton failed from eight of NIST's sixteen published
   starts, so the control has power. The unscaled damping did better than the scaled from two
   starts, and that is registered as an expected outcome, not tuned away. MINPACK's monotone
   scaling is an absence: its rule is in a listing this tree does not read. **A result carries a
   status, never a bare "converged"**: a stop by the step test while the scaled gradient is large
   is `stalled`. The evidence, registered before any run: Meyer's well-scaled formulation in DTU's
   printed 88 steps, and the ill-scaled one giving the same iterates up to the rescaling, which is
   the scaled algorithm's own invariance; DTU's 175, a count of the unscaled algorithm's rejected
   steps, reported and not gated; Nielsen's twenty problems; NIST's nonlinear sets from both starts
   and from the certified solution; and a synthetic arc in the sail's regime where Gauss–Newton
   diverges and the damped method reaches the truth.

   *Ruled 2026-10-31, on the resumed step.* The first drafting's Python runs are gone, so the two
   figures above from them, eight of sixteen and the two starts, are expectations and not evidence.
   Both are measured again in C++, the second with an unscaled control in the test code. If a
   figure differs, the text above is corrected and stays visible.
   - **What is gated on NIST:**
     - From the certified point, the run converges and does not move, to a registered LRE.
     - A status never lies. A `converged_*` run must either match the certified values to LRE 4, or
       stand at a different stationary point with a larger sum of squares, shown by an independent
       gradient. Such runs are listed by name.
     - A smaller sum of squares than NIST's, from any run, is a finding.
     - Every other status is recorded. Gauss–Newton must fail from at least one start, or the
       control has no power.
   - **Stopping tests are invariant.** Scaling the residuals or the parameters must not change a
     status, so the default gradient test is not an absolute number on residuals that carry units.
     "Large", in `stalled`, is defined and registered. DTU's absolute tests are used, with DTU's
     printed values, only to reproduce DTU's counts.
   - **A failed trial is a rejected step.** A non-finite objective, or a damped system the
     factorisation refuses, raises the damping. It ends the run only when the damping is exhausted,
     and that is `refused`.
   - **The sail arc uses a real sail.** LightSail-2's area-to-mass ratio, about 6.5 m²/kg, not a
     larger one chosen to make Gauss–Newton fail. The registry's gravity to degree 10 and SRP with
     shadow, drag off, 3 days, range from 3 stations, and a ladder of initial errors. Data and
     geometry are frozen before the first run. If Gauss–Newton does not diverge at any rung, that is
     a finding about this step's premise, and the Executor stops and reports; the arc is not
     adjusted. Drag stays off here, so the seven-cutoff question (§3.8) is still open.
   - **Corrected the same day, on the Executor's checkpoint:**
     - **Meyer's two formulations do not give "the same iterates".** Their change of variables is not
       a power-of-two rescaling, and the scaling rounds to powers of two, so the 2026-10-06 sentence
       is too strong. Exact invariance is gated where it holds, on power-of-two rescalings. For
       Meyer, the same minimiser is gated and the iterate difference is reported.
     - **`refused` also covers a run whose trials all failed.** The step test fires before the
       damping is exhausted, so a stop while the latest trial could not be evaluated reports
       `refused`, not `stalled` or `converged_*`.
   - **The two figures, measured in C++ (`75e728c`, each gate run once, every assertion held).**
     Over NIST's 54 published starts, plain Gauss–Newton reaches NIST's sum of squares from 41, the
     scaled library from 47, and DTU's unscaled algorithm from 51, all with τ = 10⁻³.
     - "Eight of sixteen" cannot be compared: the sixteen can no longer be identified. The measured
       figure is thirteen failures in 54.
     - "From two starts" is wrong: unscaled reaches from six starts where scaled does not, and
       scaled from two where unscaled does not.
     - DTU's 88 and 175 are both reproduced.
   - **Scaled damping stays the method.** Its gain is invariance, shown bit for bit, and an
     estimator whose variables are positions and velocities needs that. NIST's reach depends on the
     units its parameters happen to be published in. The same τ also does not mean the same damping:
     unscaled, τ·max aᵢᵢ damps every smaller column far harder, so the gap may be only a gentler first
     step. A default chosen from NIST after seeing NIST would be tuning, so any change of τ is
     decided on Nielsen's twenty problems, held out.
   - **Held-out result: τ stays 10⁻³.** On 29 of Nielsen's 30 instances, τ = 10⁻³ reaches 28, the
     candidate τ = 1 reaches 26 and costs more passes, and the unscaled control reaches 29.
     - *Corrected:* "only a gentler first step" did not survive. Over NIST, τ from 10⁻³ to 1 gains one
       start and leaves the other misses in place, so the amount of starting damping does not explain
       the gap. No cause is claimed.
     - Problem 17 (Osborne 1) is omitted: its table prints the abscissae where the responses belong.
       Its absence stands unless another public revision of the report prints them.
   - **`converged_residual` moves to F ≤ 10⁻²⁴ F(x₀).** At 10⁻³⁰ it sits on the rounding floor of F,
     so zero-residual problems that reached zero ended `stalled`, a status that misreports the
     result. This is a registered default changed after seeing data, by this ruling and for that
     reason. It relabels stops and is no route to reach, so the gates are run again as a new
     registered run and the old record stands beside it.
     - *Run again the same day, every assertion held.* One NIST run changed: Lanczos1 from start 2
       now stops earlier, `converged_residual` at LRE 8.13, with F about eleven times NIST's, which
       is rounding noise at that size. So the sentence "relabels stops" was too strong, and the
       scaled library's 47 of 54 above is 46 under this default, the old record standing beside it.
   - **The arc's gate is free of eclipse.** A shadow edge gives SRP a discontinuous derivative, and
     an arc whose model both generates and fits the data would hide the Jacobian's error. So the
     gate uses a high-beta geometry, with the shadow model left in the force set and the absence of
     eclipse a checked margin. That geometry is not the one a real sail flies: one eclipsing arc
     runs the same ladder and is recorded, not gated. Edge treatment stays the item carried in §3.8.
   - **The full arc runs once, here, and its log is the record.** It takes about two hours, too long
     for CI, so it stays a hidden test case with its command written down. CI runs a one-day sub-arc
     as a regression guard. That sub-arc is not this step's evidence, and its test says so.
   - **The ladder is frozen anew, because five of its six rungs could not be evaluated.** Before any
     fit, L6 refused those starts: a node fell below 3° elevation (MEAS-F-010). The Executor stopped.
     - A start that cannot be evaluated tests nothing about an estimator, so it is no rung, and it
       does not count as Gauss–Newton diverging. A trial refused during a fit does count: Gauss–Newton
       has no defence against it and Levenberg–Marquardt does.
     - Rungs are set in what governs the drift. Over 3 days, 1 cm/s of velocity alone drifts about
       8 km, while 1 km of radial position error drifts about 800 km, through the semi-major axis.
       So one ladder is in along-track phase and semi-major axis, as a TLE start errs, and one is the
       old direction, scaled. Each runs up to the edge of what can be evaluated. Finding that edge
       uses model calls only, no fit.
     - L6's refusal is right and stays. If no rung diverges inside the domain, that is the finding
       this step already registered, and it is reported, not adjusted around.
     - *Noise-free fits end `stalled` at the truth.* There the residual is the model's own noise, so
       the gradient cosine means nothing, and the fit stops at about 10⁻¹⁸ F(x₀), far above the
       zero-residual test. The stopping rule is not changed for this: with real noise the residual
       carries the fit's orthogonality, so the seeded-noise run is the test. It is registered to
       end `converged_*`. If it ends `stalled`, the rule fails for real data and comes back here.
     - *Carried to the real-data fits (L8):* every node must stay observable at every trial, so one
       observation can refuse a whole fit from a poor start. Whether a fit may edit such observations
       out is decided there.
