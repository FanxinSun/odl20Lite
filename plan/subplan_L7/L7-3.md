   - **What is gated on NIST:**
     - From the certified point, the run converges and does not move, to a registered LRE.
     - A status never lies. A `converged_*` run must either match the certified values to LRE 4, or

     "Large", in `stalled`, is defined and registered. DTU's absolute tests are used, with DTU's
     printed values, only to reproduce DTU's counts.
   - **A failed trial is a rejected step.** A non-finite objective, or a damped system the
     factorisation refuses, raises the damping. It ends the run only when the damping is exhausted,
