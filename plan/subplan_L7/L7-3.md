3. **TODO** — Levenberg–Marquardt, because a sail's trajectory over days is nothing like
   linear in its initial state and plain Gauss–Newton diverges from it.

   *Ruled 2026-10-06, on the rule-4 report.* The damping is DTU's Algorithm 3.16 in the scaled
   variables, the scaling recomputed at each iterate and the gain ratio taken on the whole
   objective, prior included: scale-invariant, as everything decided from the matrix must be. In
   the executor's exploratory run plain Gauss–Newton failed from eight of NIST's sixteen published
   starts, so the control has power. The unscaled damping did better than the scaled from two
   starts, and that is registered as an expected outcome, not tuned away. MINPACK's monotone
   scaling is an absence: its rule is in a listing this tree does not read. **A result carries a
   status, never a bare "converged"**: a stop by the step test while the scaled gradient is large
   is `stalled`. The evidence, registered before any run: Meyer's well-scaled formulation in DTU's
   printed 88 steps, and the ill-scaled one giving the same iterates up to the rescaling, which is
   the scaled algorithm's own invariance; DTU's 175, a count of the unscaled algorithm's rejected
   steps, reported and not gated; Nielsen's twenty problems; NIST's nonlinear sets from both starts
   and from the certified solution; and a synthetic arc in the sail's regime where Gauss–Newton
   diverges and the damped method reaches the truth.

   *Ruled 2026-10-31, on the resumed step.* The first drafting's Python runs are gone, so the two
   figures above from them, eight of sixteen and the two starts, are expectations and not evidence.
   Both are measured again in C++, the second with an unscaled control in the test code. If a
   figure differs, the text above is corrected and stays visible.
   - **What is gated on NIST:**
     - From the certified point, the run converges and does not move, to a registered LRE.
     - A status never lies. A `converged_*` run must either match the certified values to LRE 4, or
       stand at a different stationary point with a larger sum of squares, shown by an independent
       gradient. Such runs are listed by name.
     - A smaller sum of squares than NIST's, from any run, is a finding.
     - Every other status is recorded. Gauss–Newton must fail from at least one start, or the
       control has no power.
   - **Stopping tests are invariant.** Scaling the residuals or the parameters must not change a
     status, so the default gradient test is not an absolute number on residuals that carry units.
     "Large", in `stalled`, is defined and registered. DTU's absolute tests are used, with DTU's
     printed values, only to reproduce DTU's counts.
   - **A failed trial is a rejected step.** A non-finite objective, or a damped system the
     factorisation refuses, raises the damping. It ends the run only when the damping is exhausted,
     and that is `refused`.
   - **The sail arc uses a real sail.** LightSail-2's area-to-mass ratio, about 6.5 m²/kg, not a
     larger one chosen to make Gauss–Newton fail. The registry's gravity to degree 10 and SRP with
     shadow, drag off, 3 days, range from 3 stations, and a ladder of initial errors. Data and
     geometry are frozen before the first run. If Gauss–Newton does not diverge at any rung, that is
     a finding about this step's premise, and the Executor stops and reports; the arc is not
     adjusted. Drag stays off here, so the seven-cutoff question (§3.8) is still open.
   - **Corrected the same day, on the Executor's checkpoint:**
     - **Meyer's two formulations do not give "the same iterates".** Their change of variables is not
       a power-of-two rescaling, and the scaling rounds to powers of two, so the 2026-10-06 sentence
       is too strong. Exact invariance is gated where it holds, on power-of-two rescalings. For
       Meyer, the same minimiser is gated and the iterate difference is reported.
     - **`refused` also covers a run whose trials all failed.** The step test fires before the
       damping is exhausted, so a stop while the latest trial could not be evaluated reports
       `refused`, not `stalled` or `converged_*`.
