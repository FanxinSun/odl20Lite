8. **TODO** — Every Python file in `rewrite/` is rewritten in C++: the tools and the tests of
   tools, from L0's on. Python is then taken out of the build, the tests and CI (§5 constraint 11,
   the user's directive of 2026-10-06). The gate:
   - **An inventory, before any rewrite.** It lists every `.py` file, every place CMake, `ci.sh`,
     `bootstrap.sh` or a ctest runs Python, and every committed artefact a Python tool produced.
     Each tool's C++ replacement is named.
   - **A rule-4 and licence report** on what the C++ needs that the Python had for free:
     arbitrary-precision arithmetic, hashing, HTTP, compression and JSON. Each need is met by the
     tree's own code or by a vendored header-only library under a permissive licence. Nothing is
     installed on the machine.
   - **Each replacement proven before its Python file goes.** It reproduces its tool's committed
     artefacts byte for byte, checked against the committed files, and its tests pass as C++ tests.
   - **Python out of the build.** CMake no longer looks for Python, CI runs none, and a check
     refuses Python in the build, the tests and CI. The check is shown firing on one injected file
     (§4 rule 5).
   - **L0's own exit gate passes again without Python.** A clean clone builds, tests and
     regenerates NOTICE with one command, and CI is green from cached data alone.
